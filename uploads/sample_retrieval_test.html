Employee Leave Tracker

This HTML file contains a short project description, a JavaScript function, a sample API response, and deployment notes. It is useful for testing document retrieval and question answering.

Project Summary

The Employee Leave Tracker helps HR teams manage employee time-off requests. Employees can apply for leave, managers can approve or reject requests, and HR can view leave balances. The application uses role-based access with three roles: employee, manager, and hr_admin.

Tech Stack

  • Frontend: React
  • Backend: Node.js with Express
  • Database: MongoDB
  • Authentication: JWT

Business Rules

  • Each employee starts with 24 annual leave days per year.
  • A leave request longer than 10 days requires HR review.
  • Sick leave does not reduce annual leave balance if a medical certificate is attached.
  • Managers can only approve leave for employees in their own team.
  • Leave requests in status approved cannot be edited by employees.

JavaScript Function

function calculateRemainingLeave(totalLeave, usedLeave, pendingLeave) {
  if (totalLeave < 0 || usedLeave < 0 || pendingLeave < 0) {
    throw new Error("Leave values cannot be negative");
  }

  const remaining = totalLeave - usedLeave - pendingLeave;
  return remaining < 0 ? 0 : remaining;
}

const result = calculateRemainingLeave(24, 8, 4);
console.log("Remaining leave:", result);

Deployment Notes

The application is deployed on Render for the backend and Netlify for the frontend. MongoDB Atlas is used as the cloud database. Environment variables required for the backend are MONGODB_URI, JWT_SECRET, and PORT.

Known Issue

A previously reported bug showed that pending leave was not deducted from the dashboard preview. The fix was added in version 1.4.2 by subtracting pendingLeave inside the leave balance calculation function.
